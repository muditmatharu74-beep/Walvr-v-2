# Walvr: does the background feel personal?

Status: experiment kit, not a production feature or a completed video. Prepared October 1, 2026. No song has been selected, footage downloaded, participants contacted, or responses collected.

## The decision

Before automating footage selection or buying a large library, test whether recognizable everyday situations create more personal connection than Dark Lyrics or cinematic scenery. This is a creative hypothesis, not an established psychological effect. Do not tell participants that everyday footage is supposed to win.

The first theme is **missing someone**, using one artist-approved 20-second excerpt. Select a section that communicates absence or distance without requiring the song's full backstory. Avoid testing only with people who already have strong memories attached to that song. Record familiarity instead of assuming the visuals caused the response.

## Three edits, one timeline

Export all three at 1080 x 1920, 30 fps, H.264 MP4, exactly 20 seconds, with identical audio start/end points and loudness, identical word timings, font, text position, shadow, branding and caption animation. Use the same overlay for all three. No extra sound effects, narrative text, film grain or special transitions in only one version. Apply comparable darkness behind captions. Cut scenery and everyday footage at the same times; do not let one condition win just because it is easier to read.

| Time | Dark Lyrics control | Cinematic scenery | Everyday moments |
| --- | --- | --- | --- |
| 0–5s | Near-black field, shared caption overlay | Wide ocean at dusk | Empty seat / aisle on a night bus |
| 5–10s | Same background and overlay | Gentle waves, closer framing | Traffic seen through a rain-covered window |
| 10–15s | Same background and overlay | Quiet misty mountain ridge | An unoccupied bedroom, ordinary details |
| 15–20s | Same background and overlay | Return to ocean horizon | Return to the empty bus seat, a different five-second segment |

This is a provisional edit map. After hearing the chosen lyrics, adjust the chosen imagery, then freeze one common timing sheet for all versions before testing. Reject footage that looks like a luxury real-estate listing, contains prominent brands, obscures lyrics after vertical cropping, or relies on visible distress to communicate sadness. Ordinary surroundings are the hypothesis; generic melancholy is not the goal.

A bus is not a universal memory. After the first test, repeat with a different everyday setting and a different song before making a broad claim about relatability.

## Run the local comparison

1. Download this folder with `index.html` and `protocol.js` together. Open `index.html` in a desktop browser. It needs no server, API keys or cloud access.
2. Load the three finished, matched exports in the facilitator screen. The player checks duration and vertical dimensions. Manually confirm matching audio/captions; the player cannot verify these.
3. Start with participant 1 and use consecutive participant numbers. The six possible orders rotate evenly. Twelve listeners provide two sessions per order; aim for listeners in the intended audience. Review feedback from musicians separately as a product-use perspective.
4. Record song familiarity before viewing. Hand the screen over after setup; the viewer sees only Video 1, 2 and 3, not the hypothesis or treatment names. Do not explain the expected emotion. The visuals themselves cannot be blinded.
5. Ask the open association question first. "Nothing" is valid. Then collect personal connection and lyric readability (1–5), and a final choice of which version to watch again (including no preference).
6. Download the CSV after each session. Results exist only in the open page's memory; closing/refreshing loses them. No media or responses are uploaded. Use participant numbers, not names or contact details.

The player waits for the video to end before enabling a response. This is a workflow aid, not proof of attention. Scrubbing/replaying is possible. The player does NOT measure organic completion rate, attention, shares, or social-media retention.

## How to read the pilot

Keep each participant's three ratings paired. Report counts and individual differences, not just a pooled average:

- How many rated everyday moments higher than BOTH alternatives for personal connection?
- How many described a specific autobiographical association spontaneously? Code this from the text without looking at the treatment column first. A generic "sad" or "nice" is not a personal memory.
- Did stronger connection come with reduced lyric readability?
- Was the effect limited to people who already knew the song, a particular viewing order, or bus commuters?
- Which version was chosen for another viewing, and how many selected no preference?

A practical screening rule chosen before collecting data: consider a second pilot if at least 8 of 12 listeners rate everyday moments above both alternatives, and its median readability is no more than one point lower. This is an internal decision rule, not statistical significance or proof of demand. Count ties and no preference honestly. If the result is mixed, revise the imagery or lyric match; do not build automated matching yet. Repeat with a second song and different everyday setting before committing to a footage library.
