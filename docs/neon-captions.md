# Clean Neon and Pixel Neon

Two independent caption choices for the existing template selector:

- `clean-neon`: Montserrat 800, white phrases and cyan current-word highlighting, soft blue glow.
- `pixel-neon`: Press Start 2P 400, uppercase retro game lettering, smaller size and restrained glow to preserve pixel edges.

Both use the same word timestamps and deterministic layout: up to four words per phrase, breaks at punctuation or silence, bounded word slots that wrap within the central 80% of the frame. Long words shrink to fit. Captions sit around 69% of the frame height. Preview animation respects reduced-motion preferences.

`/caption-preview` compares the styles on a synthetic backdrop with original sample text. It has no audio, footage, account data or paid operations. The upload caption cards use the same overlay component. The original five options remain available.

## Rendering and activation

The process API accepts both identifiers. Dark Lyrics forwards the selection to Remotion, which loads the bundled font before rendering. Other templates use Creatomate text elements with explicit custom font definitions, white base words and timed cyan overlays. The Creatomate font sources are version-pinned Fontsource WOFF URLs; preview and Remotion font assets come from the same pinned npm packages. Both font packages include OFL license information. The initial font subsets are Latin; broader-script support needs matching font assets and visual review.

Both new choices use the existing standard cost of 200 credits, or 350 on Business/Studio. The selector now shares the server's cost calculation, including 100-credit basic combinations.
